========================================
AURORA AI CREATOR v1.0.0
WINDOWS
========================================

PARA INSTALAR:
Ejecuta:
AURORA-AI-CREATOR-Setup.exe

PARA USAR SIN INSTALAR:
Ejecuta:
AURORA-AI-CREATOR-Portable.exe

IMPORTANTE:
No necesitas Node.js ni npm para utilizar la aplicación instalada.
Todo el entorno de ejecución, interfaz gráfica, Live Profiler y herramientas de optimización están completamente autocontenidos.

REQUISITOS DEL SISTEMA:
- Sistema Operativo: Windows 10 / Windows 11 (64-bit)
- Arquitectura: x64
- Memoria RAM: 4 GB mínimo (8 GB recomendado)
- Almacenamiento: 250 MB de espacio libre
- Permisos: Estándar de usuario (no requiere privilegios de administrador para la versión Portable)

SOPORTE Y DOCUMENTACIÓN:
Consulta la carpeta "Documentation" para la guía rápida de inicio y notas completas de la versión 1.0.0.
